# 疯狂动物城 · 侦探档案

网页 3D 开放世界侦探游戏（Three.js，全部程序化建模，无外部模型文件）。

## 运行

```bash
npm install
npm run dev      # 打开 http://localhost:5173
```

## 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标（点击画面锁定）/ 右键拖动 | 视角；滚轮缩放 |
| Shift | 奔跑（驾驶时加速） |
| Space | 跳跃 |
| E | 互动：对话、调查线索、和路人打招呼 |
| Tab | 切换朱迪 / 尼克 |
| Q | 侦探感知（显示附近线索） |
| F / H | 上下警车 / 警笛 |
| J | 侦探档案（证据、人物、进度） |
| M | 全屏地图，点击地标快速出行 |
| Esc | 菜单（切换昼夜、回到 ZPD、重置存档） |

## 地图

撒瓦纳中央区（ZPD、中央车站、市政厅、喷泉广场、车管所）、小型啮齿镇、冰川镇、撒哈拉广场、雨林区、兔窝镇，运河与跨河大桥相连。

## 案件（均为非暴力案件）

1. 消失的甜甜圈 2. 迷你皇冠失窃案 3. 冰棍工厂大融化 4. 雨林停雨之谜 5. 棕榈宫殿的赝品 6. 兔窝镇麦田怪圈

在 ZPD 门口找牛局长领取。进度自动保存在浏览器本地。

## 结构

- `src/world/layout.js` 地图布局（唯一坐标来源）
- `src/world/districts/*.js` 各地区建模
- `src/chars/` 朱迪、尼克与 23 种动物
- `src/game/cases.js` 案件剧本（想加新案件就在这里写）
- `src/game/detective.js` 侦探系统
